## Root-cause synthesis (what was *actually* the problem)
- The two weak tests share one root cause: **a round-trip through a parser is not evidence about
  the bytes**. `csv.reader` accepts both the correctly-quoted and the unquoted form of a mid-field
  quote, so a test that only round-trips cannot distinguish a correct writer from one that never
  quotes. The fix is always to assert on the raw response bytes.
- The missing PRD issue is an infrastructure gap (the `prd-projection` pass has not created it),
  not a defect in this run — but it leaves the terminal without a tracker target, which the
  command's own contract assumes exists.
